# Stellar Strike（星際雷霆）

以 SwiftUI 與 SpriteKit 製作的 iPhone／iPad 直立捲軸射擊遊戲原型。

## 建置

1. 使用支援 iOS 27 SDK 的 Xcode 開啟 `igo3.xcodeproj`。
2. 選擇 `igo3` Scheme 與 iPhone 或 iPad 模擬器。
3. 執行 Product > Run。
4. 單元測試使用 Product > Test；測試 Target 為 `igo3Tests`，採 Swift Testing。

目前 deployment target 為 iOS 27.0，支援 iPhone 與 iPad，介面鎖定直向。

## 操作

- 戰鬥畫面以相對拖曳移動戰機；戰機不會跳到首次觸碰位置。
- 可在設定調整拖曳靈敏度與底部手指偏移。
- 武器自動射擊；右下角能量充滿後可發動雷霆爆發並清除敵彈。
- 綠色道具提升火力至 P3，粉紅色修復生命，藍色提供一次傷害護盾。
- 新星使用集中雙連發、暴風使用扇形散射、神盾使用可貫穿小怪的雷射。
- 勝利後依通關、受傷次數與分數取得最多三星，可重試或前往下一關。

## 功能狀態

- 五關、三機體、解鎖、強化、金幣、高分與本機存檔。
- 三類敵機與資料化波次：暖身、交錯編隊、混合敵群、Boss 前補給。
- Boss 三階段、轉階段無敵、階段大招與攻擊預警。
- 結算去重由每場 `GameSession` 管理；連續重試可各自正常結算。
- 版本 1 存檔可遷移至版本 2；無法完整解碼時保留原始備份並盡量救回主要欄位。
- 使用固定邏輯場景 390 × 844 搭配 `aspectFit`，避免不同螢幕比例裁切遊戲區域。

## 測試範圍

`igo3Tests` 涵蓋：

- 連續重試各自結算。
- 同一場不可重複發獎。
- 玩家接觸 Boss 不移除 Boss。
- 戰鬥結束後生命與結果不再改變。
- 共用敵彈清除。
- 舊版存檔遷移。

## 已知限制

- 背景音樂與音效開關已保存，但正式音訊素材尚未加入。
- 程式化機體與敵機仍為原型美術。
- UI 自動化與實機效能測試尚未建立；發布前應在多款 iPhone 與 iPad 實機驗證長時間高彈幕效能。
